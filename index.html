Security SDK used by 1M+ people

Context

Software for a patented resin 3D printer

3DScales, Beirut06/2016 – 10/2017Software Engineer
Context
A bottom-up resin printer: a projector cures each layer of liquid resin through a clear tank floor while a platform lifts the model one layer at a time.
Problem
Combining optics, mechanics, electronics and software so that every layer is exposed precisely and in sync with Z-axis motion.
Approach
Integrated an open-source JavaScript slicer into the printer application to turn models into layer masks, then sequenced exposure with Z-axis motion. Worked in a multidisciplinary team of software and mechanical engineers.
Result
A patented SLA printer taken from prototype to working product.
